# Fundación Familia C.E.A. Chile

Sitio web de la Fundación Familia C.E.A. — *Inclusión desde el corazón*.

Es una sola página (`index.html`) con los estilos y las fotos incluidos, así que basta con abrirla en el navegador o publicarla en cualquier hosting estático (GitHub Pages, Cloudflare Pages, Netlify).
